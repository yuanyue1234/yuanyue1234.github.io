Moonlit Log

偏视觉编辑器的小程序项目，而不是普通表单工具。

月光手帐以“收集实物周边并做成电子手帐”为主流程。用户可以上传或拍摄小卡、票根、冰箱贴等素材，整理进贴纸库，再进入 Canvas 手帐页进行拖拽、缩放、旋转、排版和导出。

微信原生小程序 Canvas 2D OffscreenCanvas wx.Storage AI 标签方案 JS PDF
50最多 50 步撤销重做，每页独立历史。
8+88 种主题与 8 种手帐模板。
500ms防抖自动保存，降低编辑丢失风险。
我负责的部分
  • 设计小程序信息架构：首页、编辑器、贴纸库、素材提取、模板选择。
  • 实现 Canvas 2D 自绘编辑器的元素渲染、选中态、拖拽缩放、图层顺序和页面保存。
  • 规划贴纸库的搜索、分组、收藏、批量上传和一键放入手帐流程。
技术难点
  • 在小程序 Canvas 环境中处理不同元素类型的坐标、缩放、旋转与命中检测。
  • 用 OffscreenCanvas 缓存纸面材质和图片效果，降低重复渲染成本。
  • 图片白边、纸贴、阴影按透明主体轮廓处理，避免变成矩形贴片。
成果亮点
  • 形成“收集素材 -> 进入贴纸库 -> 放入手帐 -> 导出”的完整闭环。
  • 交互风格从普通工具页升级为暗色电绿色、强识别的编辑器界面。
  • 项目文档包含产品升级方案、最小成功案例和备案说明，便于持续迭代。

MousePointer

把鼠标指针方案管理做成可下载的 Windows 工具。

MousePointer 是面向新手用户和鼠标指针制作者的 Windows 图形化工具。它把原本分散、繁琐的指针方案导入、编辑、预览、应用、资源库管理和打包流程，整理成一个可下载的桌面应用。

Python PySide6 PyQt-Fluent-Widgets Windows GUI Release 打包 GitHub Pages
.cur/.ani支持指针文件、图片、压缩包、exe 与文件夹导入。
v2.1.2已有单文件绿色版 Release 下载入口。
资源库在线资源库与本地应用形成项目闭环。
我负责的部分
  • 围绕鼠标指针配置管理设计桌面工具流程：导入、识别、预览、应用、打包。
  • 使用 PySide6 搭建 Windows 图形界面，并参考 Fluent 风格提升控件质感。
  • 补齐 GitHub 仓库、Release 下载、在线资源库和项目展示页，让项目可被直接体验。
技术难点
  • 指针资源格式分散，需要兼容 `.cur`、`.ani`、压缩包、文件夹和安装包导入。
  • 动态指针需要预览与状态切换，避免用户应用前只能反复试错。
  • 桌面工具不只要能运行，还要有打包、说明、资源入口和截图证据。
成果亮点
  • 从“AI 辅助想法”推进到真实可下载的 Windows 软件。
  • 界面包含鼠标方案、资源库、方案切换等完整功能分区，产品边界清晰。
  • 适合作为 Python 应用开发、桌面 GUI、Release 发布意识的面试项目。

Python crawler

从电影数据采集，到清洗入库，再到可视化分析。

豆瓣项目被拆成独立的数据工程作品来讲述：通过 Python 获取 Top250 电影数据，按影片、评分、年份、国家、类型标签等字段清洗为 JSON，再导入 Django/MySQL，最终用 pyecharts 和 ECharts 做多维度展示。

Python requests JSON MySQL pyecharts ECharts
Top250电影榜单数据查询、分页与搜索。
10本地 JSON 数据文件分批导入数据库。
6+饼图、柱状图、折线、词云、散点、3D 柱图。
我负责的部分
  • 整理电影字段结构，处理豆瓣 ID、标题、评分、年份、国家和类型标签。
  • 编写导入脚本，将 JSON 数据去重后写入 Django Movie 模型。
  • 用 pyecharts 生成国家分布、年代分布、标签词云、评分统计和 3D 图表。
技术难点
  • 爬取数据字段存在缺失和格式不一致，需要在导入前做兜底处理。
  • 国家、类型、年份属于多值标签，需要拆分统计后再进入图表。
  • 大图表页面要兼顾可读性和交互性，使用数据缩放与图表工具箱辅助浏览。
成果亮点
  • 把单纯爬虫结果沉淀为可查询、可分页、可可视化的数据系统。
  • 毕业设计中完整写明了数据展示、可视化和后端实现链路。
  • 可作为面试中讲解“数据采集到产品展示”的完整案例。

Django + Vue3

有前台、有登录、有留言、有后台配置的个人网站系统。

个人博客系统采用前后端分离架构：Django REST Framework 提供接口，Vue3 + Vite 构建前端页面，Pinia 管理登录状态，Axios 处理请求与认证头，JWT 完成身份校验，并通过 MySQL 持久化用户、留言、导航和站点配置。

Vue3 3.5 Vite 6 Pinia Vue Router Axios Django REST JWT
DRF留言板、用户、站点配置接口。
JWT登录后携带令牌访问个人中心。
AdminDjango 后台维护数据和配置。
我负责的部分
  • 搭建 Vue3 页面结构、路由、登录注册、个人中心和留言板交互。
  • 接入 Axios 请求封装、Pinia 登录态、JWT 刷新与路由守卫。
  • 使用 Django Admin 管理电影数据、留言、用户和站点配置。
技术难点
  • 前后端分离调试涉及跨域、Cookie、JWT Header 与开发代理配置。
  • 用户状态需要在刷新页面后恢复，并保证未登录时能正确跳转登录页。
  • 站点配置采用单例模式，避免多个配置项造成页面内容不一致。
成果亮点
  • 完整覆盖游客、注册用户和管理员三类角色。
  • 既有博客展示，也有留言互动和后台维护，项目可作为综合 Web 系统讲述。
  • 使用 Vue3、Pinia、Router、Axios 的组合，能体现现代前端开发能力。
