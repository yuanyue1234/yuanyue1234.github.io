这是当前最适合作品集首屏展示的项目：它有真实用户场景、桌面 GUI、资源导入、预览、打包和在线资源库。

MousePointer

面向新手用户和鼠标指针制作者的 Windows 图形化工具。它把原本分散、繁琐的指针方案导入、编辑、预览、应用和打包流程，整理成一个可下载的桌面应用。

IMPORT

支持 .cur、.ani、图片、压缩包、exe 和文件夹导入。

INF PARSE

导入资源包时自动识别 .inf，可处理多份指针方案。

PREVIEW

右侧实时预览静态与动态鼠标指针，.ani 可直接播放。

PACKAGE

支持 GIF 截图导出、后台驻留和单文件绿色版发布。
